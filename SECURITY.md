# Security policy

This policy covers the **Rocky Riders** app (Android and iPhone), its cloud services, and this website.

## Reporting a problem

If you think you've found a security problem, for example a way to see or change data you shouldn't,
to get organiser or marshal access without an invite, or to sign in as someone else, please tell us
**privately**:

**Email:** adminrockyriders@gmail.com
**Subject:** `Security: <short description>`

Please **don't** open a public GitHub issue or post it anywhere public until we've fixed it.

It helps if you include:

- what the problem is and what someone could do with it
- the steps to reproduce it (app version, Android or iPhone, which screen)
- screenshots, if you have them

## What happens next

The app is run by club volunteers, so we can't promise fixed response times. We will:

- reply to say we've received the report, normally within a week
- keep you updated while we look into it and fix it
- credit you once it's fixed, if you'd like that

## Please don't

- access, change or delete other people's data beyond what you need to show the problem
- run automated scans or high-volume tests against the app's servers
- try to trick or pressure club members (social engineering)

If you act in good faith and follow this policy, the club won't take action against you for your report.

## Supported versions

Only the latest version of the app from Google Play or the App Store is supported. If you can, please
check that the problem still happens in that version before reporting it.
